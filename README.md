# Démineur

Un démineur moderne jouable gratuitement dans le navigateur, sans inscription. Révélez les cases sans mine à l’aide des indices, et signalez les cases suspectes. Le site propose notamment des statistiques, un classement local, l’annulation et le rétablissement des actions, ainsi que l’import et l’export de grilles.

[Jouer au Démineur](https://breizhimic.github.io/Demineur/)
